# E-Commerce Portal

This is a front-end web application for a simple e-commerce portal, created as a part of a college assignment. The entire project is built within a **single `index.html` file**, demonstrating the use of vanilla HTML, CSS, and JavaScript to create an interactive user experience.

## ✨ Features

This project fulfills the following assignment requirements:

1.  **Site Navigation:** A complete navigation bar that allows users to switch between different "pages" (sections) of the website, including:
    * Home
    * Product Items
    * Contact Us
    * About Us
    * Login/Register
    * My Account

2.  **Form Validation:** Client-side input validation for:
    * **User Registration:** Checks for valid username length, email format, and password length.
    * **User Login:** Checks that email and password fields are not empty.
    * Error messages are displayed dynamically for invalid inputs.

3.  **User Dashboard:** A "My Account" page that displays static mock-ups for essential e-commerce features:
    * Orders List
    * Wishlist
    * Comments & Reviews
    * Customer Care
    * Reporting Options

## 💻 Technologies Used

* **HTML5:** For the structure and content of the website.
* **CSS3 (Internal):** For all styling, layout, and responsiveness, all written inside `<style>` tags.
* **JavaScript (Internal):** For all interactivity, including page switching and form validation, all written inside `<script>` tags.

## 🚀 How to Run

Since this is a single-file project with no external dependencies:

1.  Download or clone this repository.
2.  Open the `index.html` file directly in any modern web browser (like Google Chrome, Firefox, or Microsoft Edge).
3.  That's it! You can now browse the site and test the form validations.
